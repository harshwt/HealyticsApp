# Healytics – Intelligent Diabetes Prediction and Awareness App

Healytics is a machine learning-powered web application designed to assess diabetes risk and promote health awareness. Built with Python, the application uses a pre-trained classification model and data scaling pipeline to deliver real-time predictions based on user health metrics.

## Features

* **Diabetes Risk Prediction:** Evaluates user-inputted health parameters using a trained machine learning model (`diabetes_model.pkl`).
* **Automated Feature Scaling:** Standardizes input data using a pre-fitted scaler (`scaler.pkl`) to ensure accurate model inference.
* **Interactive Web Interface:** Provides an accessible front-end (`Healytics_app.py`) for entering health metrics and viewing awareness insights.
* **DevContainer Support:** Includes `.devcontainer` configuration for consistent, containerized development environments.

## Project Structure

```text
HealyticsApp/
├── .devcontainer/        # Development container configuration
├── Healytics_app.py      # Main application script
├── diabetes_model.pkl    # Serialized machine learning model
├── scaler.pkl            # Serialized feature scaler
└── requirements.txt      # Python dependencies
```

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd HealyticsApp
   ```

2. **Create and activate a virtual environment (optional):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. **Install the required dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the main application script locally:

```bash
streamlit run Healytics_app.py
```
*(Note: If the app uses Flask or another framework instead of Streamlit, run `python Healytics_app.py`.)*
